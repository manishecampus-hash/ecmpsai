1 Executive Summary & Business Intent

Instead of burdening prospective students with hundreds of unstructured online university listings, the eCampus AI Matching Engine analyzes individual student credentials in real-time to compute individualized compatibility metrics.

This automated matching system delivers value on two fronts:

  • For Students: Minimizes cognitive friction and decision paralysis by highlighting degree programs that directly fit their budget and eligibility.
  • For Partner Universities: Delivers pre-qualified, high-intent student inquiries that match statutory admission eligibility and tuition expectations.

2 The 3 Core Evaluation Dimensions

The query pipeline executes against the central MongoDB course catalog using three mandatory student profile criteria:

Dimension Input Attribute Business Processing Logic
1. Program Intent coursePreference Normalizes free-form preferences into canonical degree tokens (e.g. MBA, MCA, BCA, BBA, DBA, B.Com) to query matching university programs.
2. Budget Tolerance budget Translates stated budgets (e.g. ₹2.0L – ₹2.5L) into numerical fee ranges. Ensures student tuition expectations match university fee structures.
3. Academic Eligibility highestQualification Audits student credentials (12th, Diploma, Bachelor's, Post-Graduate) against UGC/AICTE degree pre-requisites.

3 Compatibility Scoring Algorithm

Compatibility scores are computed on a normalized curve with a calibrated floor and ceiling:

MatchScore = clamp(76, 98, Base(52) + DegreeFit + Eligibility + BudgetFit + CategoryWaiver + UniRating)
Scoring Component Max Weight Allocation Rules
Degree Fit +25 pts +25 pts for exact course match.
+15 pts for feeder degrees (BCA → MCA, BBA → MBA).
+5 pts for cross-disciplinary courses.
Eligibility Match +10 pts +10 pts for completed pre-requisites (e.g. Bachelor's grad taking a Master's degree).
+6 pts if bridge verification or non-standard review is required.
Budget Alignment +10 pts +10 pts if fees fall within student budget.
+8 pts if under budget (savings bonus).
+5 pts if moderately above budget (bridgeable via Zero-Cost EMI).
Category Advantage +3 pts +3 pts for Defence, Merit, or Reserved categories eligible for statutory scholarship quotas.
University Quality +2 pts +2 pts institutional reputation boost for partner universities holding ratings ≥ 4.5.

5 Business Continuity & Fallback Logic

Zero-Drop-Off Guarantee
Student bounce rates spike if search queries produce "0 Results Found". The engine implements two automatic guardrails:
  • Dynamic Budget Relaxation: If a student selects an unrealistically low budget for a premium specialized degree, the database query automatically relaxes the budget constraint and surfaces verified Zero-Cost EMI options.
  • Curated Standby Catalog: If database network latency occurs, pre-verified partner university benchmarks (Chandigarh University, NMIMS, Amity, Manipal) are dynamically scored and served to ensure zero UI interruption.
